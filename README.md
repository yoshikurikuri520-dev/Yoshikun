# YoshikunGPT iPhone V4

## 開き方
1. macOSで `YoshikunGPT.xcodeproj` をXcode 16以降で開きます。
2. TARGETS → YoshikunGPT → Signing & Capabilities で自分のTeamを選択します。
3. 接続したiPhoneまたはシミュレータを選び、Runします。

## 追加内容
- SwiftUI + WKWebView のiPhoneアプリ化
- iPhoneセーフエリア・キーボード対応
- 人格を4種類追加
- 語彙・言い換え辞典
- 文章整形、アイデア、ToDo、タイマー、メール雛形、会議メモ、質問具体化、休憩機能
- 日常、予定、旅行、料理、健康、家計、文章作成などの応答レパートリー拡張

## 注意
- 完全オフラインのルールベース応答です。最新情報検索や本格的な生成AIにはAPI接続が必要です。
- App Store提出には、独自のアプリアイコン、プライバシー説明、署名、審査対応が必要です。
- 同梱音源の配布権・利用権は提出前に必ず確認してください。
